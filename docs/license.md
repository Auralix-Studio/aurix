# Licencias · Aurix

## Aplicación y marca

Aurix es un producto de Auralix Studio. Que esta web y los archivos de distribución sean públicos no concede una licencia sobre el código de la aplicación. El nombre y el logotipo de Aurix pertenecen a Auralix Studio.

## Componentes de terceros

Aurix incluye PRoot (GPL-2.0-or-later), talloc (LGPL-3.0-or-later), libandroid-shmem (BSD-3-Clause), Eclipse JGit (EDL-1.0), sora-editor (LGPL-2.1) y las tipografías Geist Mono, Schibsted Grotesk y Unbounded (SIL OFL 1.1). La imagen de Alpine Linux que se descarga si activas Linux se rige por la licencia de cada uno de sus paquetes.

## Código fuente de los componentes copyleft

PRoot y talloc se distribuyen sin modificar, tal como los publica el proyecto Termux, y se ejecutan como procesos independientes. Su código fuente está en https://github.com/termux/proot (versión 5.1.107) y https://www.samba.org/ftp/talloc/ (versión 2.5.0). sora-editor se usa sin modificar y su código fuente está en https://github.com/Rosemoe/sora-editor (etiqueta 0.24.7). Los paquetes del sistema base de la terminal se compilan desde las fuentes en https://github.com/Auralix-Studio/aurix-packages.
