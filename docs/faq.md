# Preguntas frecuentes · Aurix

## ¿Por qué tengo que iniciar sesión?

Aurix exige iniciar sesión con Google o con GitHub. Con GitHub, además, puedes clonar repositorios privados y subir cambios. Aurix no crea cuentas propias ni guarda tus datos en servidores de Auralix Studio.

## ¿Qué lenguajes resalta?

Treinta y tres: Kotlin, Java, Rust, JavaScript, TypeScript, Python, Go, C, C++, Dart, SQL, Shell, JSON, YAML, TOML, CSS, HTML, Markdown, Ruby, PHP, Lua, C#, Swift, Perl, PowerShell, R, Groovy, Scala, Haskell, Julia, Dockerfile, Makefile y Batch.

## ¿En qué idiomas está la aplicación?

En inglés, español, portugués, francés y alemán.

## ¿Funciona sin conexión?

Editar, buscar y usar la terminal del sistema no necesitan Internet. Iniciar sesión, clonar, hacer pull o push y descargar la imagen de Linux sí.

## ¿Mis archivos salen del dispositivo?

No, salvo lo que tú envíes, por ejemplo con git push. Aurix no sube tus archivos a servidores propios.

## ¿Puedo usar mi teclado habitual?

Sí. Aurix usa el teclado normal del sistema, el que ya tengas instalado. Opcionalmente muestra una fila de símbolos cuando el teclado está abierto.
