# Privacidad · Aurix

## Responsable

Auralix Studio (https://aurx.pro) es el responsable de Aurix, el editor de código para Android con identificador pro.auralix.aurix. Contacto: auralix@outlook.es. Última actualización: 23 de noviembre de 2026.

## Resumen

Aurix no tiene servidores propios, no muestra anuncios y no incluye herramientas de analítica ni de seguimiento. Lo que haces en la aplicación se queda en tu dispositivo, salvo lo que tú mismo envías a servicios de terceros, por ejemplo al subir código a GitHub.

## Datos que trata la aplicación

Cuenta de Google o GitHub (nombre, correo y foto): para iniciar sesión y mostrar tu cuenta; se guarda solo en el dispositivo. Token de acceso de GitHub: para clonar repositorios privados y subir cambios; se guarda en el dispositivo, cifrado con una clave del Android Keystore, y solo se envía a GitHub cuando usas Git. Tus archivos y proyectos: se quedan donde tú los guardes (almacenamiento de la aplicación o carpetas que elijas) y solo salen si tú los subes con Git o los compartes. Ajustes (tema, tamaño de letra…): solo en el dispositivo.

## Copias de seguridad

Aurix desactiva la copia de seguridad automática de Android, así que estos datos no se copian a la nube de Google.

## Conexiones a Internet

Aurix solo se conecta cuando una acción tuya lo necesita: el inicio de sesión con Google (mediante el sistema de credenciales de Android) o con GitHub (github.com y api.github.com); Git contra los repositorios que tú elijas; y, si activas Linux, la descarga única de una imagen mínima de Alpine Linux desde dl-cdn.alpinelinux.org, verificada con SHA-256. Lo que descargues o ejecutes desde la terminal (paquetes, dependencias) lo decides tú y va directamente al servicio que elijas.

## Permisos

Internet: para las acciones descritas. Acceso a todos los archivos (opcional): para abrir y editar proyectos en carpetas del dispositivo y que Git y la terminal trabajen con ellos; puedes usar Aurix sin concederlo, con su carpeta propia. Notificaciones y servicio en primer plano: para avisarte de que hay sesiones de terminal activas en segundo plano y permitirte detenerlas. En Android 10 y anteriores, el acceso al almacenamiento usa los permisos clásicos de lectura y escritura.

## Terceros

Al iniciar sesión con Google o con GitHub, esos servicios tratan tus datos según sus propias políticas. Si instalas Aurix desde Google Play, Google puede tratar datos según su política. Las licencias de los componentes de terceros están en la página de licencias.

## Tus derechos y cómo borrar tus datos

Cerrar sesión en los ajustes de Aurix borra del dispositivo la cuenta y el token guardados. Desinstalar la aplicación borra todos sus datos y su carpeta propia; los archivos que guardaste en otras carpetas se quedan donde están, porque son tuyos. Aurix no crea cuentas propias: no hay datos tuyos en servidores de Auralix Studio que borrar. Para los datos que tengan Google o GitHub, usa sus propias herramientas.

## Menores

Aurix es una herramienta de programación y no está dirigida a menores de 13 años.

## Esta web

El sitio se aloja en GitHub Pages y, en las páginas de descargas e historial, consulta la API pública de GitHub para mostrar publicaciones. No incluye formularios de cuenta, cookies de seguimiento, analítica ni anuncios. GitHub recibe las solicitudes de navegación y de consulta.

## Cambios y contacto

Si esta política cambia, se publicará aquí la versión nueva con su fecha. Para consultas sobre privacidad escribe a auralix@outlook.es. No envíes contraseñas, tokens ni código privado por correo.

# Privacy policy (English)

## Controller

Auralix Studio (https://aurx.pro) is responsible for Aurix, the Android code editor with application ID pro.auralix.aurix. Contact: auralix@outlook.es. Last updated: November 23, 2026.

## Summary

Aurix has no servers of its own, shows no ads and includes no analytics or tracking tools. What you do in the app stays on your device, except what you yourself send to third-party services, for example when you push code to GitHub.

## Data the app handles

Google or GitHub account (name, email and photo): to sign you in and show your account; stored only on the device. GitHub access token: to clone private repositories and push changes; stored on the device, encrypted with an Android Keystore key, and sent only to GitHub when you use Git. Your files and projects: they stay where you save them (the app storage or folders you choose) and leave only if you push them with Git or share them. Settings (theme, font size…): only on the device.

## Backups

Aurix turns off Android automatic backup, so this data is not copied to Google cloud.

## Internet connections

Aurix connects only when an action of yours needs it: signing in with Google (through the Android credential system) or with GitHub (github.com and api.github.com); Git against the repositories you choose; and, if you enable Linux, a one-time download of a minimal Alpine Linux image from dl-cdn.alpinelinux.org, verified with SHA-256. What you download or run from the terminal (packages, dependencies) is your decision and goes directly to the service you choose.

## Permissions

Internet: for the actions above. All files access (optional): to open and edit projects in device folders and let Git and the terminal work with them; you can use Aurix without granting it, using its own folder. Notifications and foreground service: to tell you that terminal sessions are running in the background and let you stop them. On Android 10 and earlier, storage access uses the classic read and write permissions.

## Third parties

When you sign in with Google or GitHub, those services process your data under their own policies. If you install Aurix from Google Play, Google may process data under its policy. Third-party component licenses are on the licenses page.

## Your rights and deleting your data

Signing out in Aurix settings deletes the saved account and token from the device. Uninstalling the app deletes all its data and its own folder; files you saved in other folders stay where they are, because they are yours. Aurix creates no accounts of its own: there is no data of yours on Auralix Studio servers to delete. For data held by Google or GitHub, use their own tools.

## Children

Aurix is a programming tool and is not directed at children under 13.

## This website

The site is hosted on GitHub Pages and, on the downloads and history pages, queries the public GitHub API to show releases. It has no account forms, tracking cookies, analytics or ads. GitHub receives the browsing and query requests.

## Changes and contact

If this policy changes, the new version will be published here with its date. For privacy questions write to auralix@outlook.es. Do not send passwords, tokens or private code by email.
