Acerca

Un editor pensado para el teléfono

Aurix es un editor de código nativo para Android. Dibuja solo las líneas visibles, usa el teclado normal del sistema (no trae teclado propio) y abre archivos, comandos y Git con gestos de borde y un botón flotante, para que el código ocupe toda la pantalla.

Editor, terminal y Git en un solo lugar

Edita con pestañas y resaltado de sintaxis, abre una terminal real y usa Git (clonar, ramas, stash, fusiones y un resolutor visual de conflictos) sin salir de la aplicación.

El estado, sin adornos

Aurix está en desarrollo y todavía no se ha publicado en Google Play. Hasta ahora se ha probado en un emulador de Android; falta probarlo en dispositivos reales y en procesadores ARM. Lo que aún no existe se muestra como tal dentro de la propia aplicación.
